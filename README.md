# Stellar Provenance

## Outcome

Build a space exploration game inspired by Elite Dangerous, where space objects
and game content are tokenized and run using Web3 or on-chain technology.
Creators can thrive through space exploration and own pieces of the game's
universe and objects in it, inspired by The Sandbox.

Ownership refers to in-game digital assets, not legal ownership of real
celestial bodies.
